# AI Skope

Your browser, split in two: the page on the left, a full-height AI pane on the
right. Aim at what you want to ask about — pick an element, drag-select text,
or attach a file from your own disk — and ask.

The answers come from coding agents already installed on your computer.

## No cloud service

AI Skope talks to one thing: **AI Skope Server**, a small program you run
yourself. That server drives the agents you already use — Claude Code, Codex,
pi, omp, opencode — and whatever model they are configured with is what
answers.

So your provider keys stay where they already are. There is no account, nothing
to sign into, and no server of ours anywhere in the path.

## What it reads, and when

Nothing, until you say so.

The extension requests no access to any website when you install it. The first
time you pick an element or select text on a site, your browser asks whether to
allow that site, and you decide — one site at a time.

Page content leaves your browser only when you pick something, select
something, or answer yes to *"send this page's text"*. You can set that to
**Always** or **Never**, and block individual sites outright.

The [privacy policy](privacy) says exactly where everything goes.

## Getting started

[Install AI Skope](install) — the server, the extension, and pairing the two.

You need macOS or Linux, and at least one supported coding agent already
working from your terminal.
